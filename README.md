# Saq Clinic Landing Platform

Этот репозиторий содержит бэкенд на .NET 8 и фронтенд на Angular 17 для лендинга косметологической клиники «Saq Clinic».

## Структура проекта

- `backend/SaqClinic.Api` — минимальное API .NET 8, отдающее данные о клинике и готовое к публикации статических файлов (сборка Angular).
- `frontend/` — приложение Angular 17 со страницами:
  - Косметологические услуги;
  - Обучение на косметолога;
  - Магазин косметики.

## Локальный запуск

1. Установите .NET 8 SDK и Node.js (18+) с Angular CLI.
2. В папке `frontend` выполните `npm install`, затем `npm run start` для локальной разработки (прокси `proxy.conf.json` направит запросы на API).
3. В папке `backend/SaqClinic.Api` выполните `dotnet run` для запуска API (по умолчанию порт 5000).

## Production-сборка

1. В папке `frontend` выполните `npm run build`. Результат появится в `frontend/dist/saq-clinic-landing`.
2. Скопируйте содержимое сборки в `backend/SaqClinic.Api/wwwroot` (создайте папку, если её нет) или настройте CI/CD на автоматическую публикацию.
3. В корне API выполните `dotnet publish -c Release` и разверните артефакт на нужный хостинг.

## Дополнительные шаги по развёртыванию

- Настройте DNS-запись (например, `clinic.example.com`) на IP-адрес сервера с приложением.
- Настройте HTTPS-сертификат (Let’s Encrypt или сертификат провайдера) через обратный прокси (Nginx/Apache/IIS).
- Настройте CI/CD для автоматической сборки и публикации (GitHub Actions/Azure DevOps).

## Контакты

Авторский шаблон предназначен для дальнейшего наполнения реальным контентом и интеграциями (запись на приём, CRM и т.д.).
